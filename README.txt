# Website — Rui Ricardo dos Santos Mugagine

Website institucional multipágina em português de Portugal.

## Estrutura
- index.html — página inicial
- sobre.html — apresentação institucional
- servicos.html — oito áreas de serviços
- servicos/*.html — página individual para cada área
- equipa.html — secção preparada para futura equipa
- perguntas.html — perguntas frequentes
- noticias.html — área preparada para publicações
- contactos.html — contactos e formulário visual
- style.css / script.js — estilos e interacções
- assets/logo-rui-mugagine.png — logótipo fornecido

## Antes de publicar
1. Substituir os campos [Inserir ...] pelos contactos e localização reais.
2. Confirmar a biografia, habilitações e dados profissionais.
3. Rever os textos de serviços e confirmar que correspondem à actividade efectivamente prestada.
4. Ligar o formulário a um serviço de envio ou backend. Neste pacote, o formulário não envia dados.
5. Substituir a fotografia de fundo de demonstração por uma imagem autorizada do escritório/advogado, se desejado.

O website utiliza uma paleta monocromática (preto, branco e cinzentos), retirada da identidade visual do logótipo.
